# Medical Knowledge RAG Store

This directory contains curated clinical guidance documents and WHO/MoHFW public health triage protocols used by `rag_service.py`.

## Knowledge Source Requirements
All knowledge added to this directory MUST include full source metadata:
- Title
- Organization
- Source URL
- Publication Date
- License (Public Health Guidance / Open Data)
- Last Verified Date

## Guidance Standard
DO NOT scrape unverified or generic advice websites. Only official government health authorities, WHO guidelines, or peer-reviewed emergency triage protocols should be indexed.
